SELECT 
    ano AS ANO_ELEICAO,
    sigla_uf AS SG_UF,
    genero AS DS_GENERO,
    raca AS DS_COR_RACA,
    cargo AS DS_CARGO,
    resultado AS DS_SIT_TOT_TURNO
FROM `basedosdados.br_tse_eleicoes.candidatos`
WHERE sigla_uf = 'SP'
  AND ano IN (2012, 2016, 2020, 2024)
"""

# O projeto 'billing_project_id' pode ser deixado com um nome de projeto do Google Cloud ou configurado no GCP
df_tse = bd.read_sql(query, billing_project_id="tcc-univesp-analise")

df_tse.to_parquet(caminho_parquet, index=False)

import pathlib
import pandas as pd

# 1. Carregar bases
BASE_DIR = pathlib.Path(r"C:\Users\Artur\TCC_UNIV")
DATA_DIR = BASE_DIR / "data"

df_tse = pd.read_parquet(DATA_DIR / "tse_candidatos_sp_2012_2024.parquet")

# 2. Dicionários de Padronização (TSE -> IBGE)
mapa_genero = {
    "MASCULINO": "MASCULINO",
    "FEMININO": "FEMININO"
}

mapa_raca = {
    "BRANCA": "BRANCA",
    "PRETA": "PRETA",
    "PARDA": "PARDA",
    "AMARELA": "AMARELA",
    "INDÍGENA": "INDIGENA",
    "INDIGENA": "INDIGENA"
}

# 3. Aplicação do Tratamento e Filtros
df_tse_limpo = df_tse.copy()

# Normalizar texto (remover espaços sobressalentes)
df_tse_limpo["DS_GENERO"] = df_tse_limpo["DS_GENERO"].astype(str).str.strip().str.upper()
df_tse_limpo["DS_COR_RACA"] = df_tse_limpo["DS_COR_RACA"].astype(str).str.strip().str.upper()

# Mapear variáveis padronizadas
df_tse_limpo["sexo_std"] = df_tse_limpo["DS_GENERO"].map(mapa_genero)
df_tse_limpo["cor_raca_std"] = df_tse_limpo["DS_COR_RACA"].map(mapa_raca)

# Descartar registros sem informação demográfica válida
df_tse_limpo = df_tse_limpo.dropna(subset=["sexo_std", "cor_raca_std"])

# 4. Exportar base pronta para a etapa de Análise
caminho_saida = DATA_DIR / "tse_candidatos_sp_limpo.parquet"
df_tse_limpo.to_parquet(caminho_saida, index=False)

print(f"✅ Processamento concluído!")

import pathlib
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

BASE_DIR = pathlib.Path(r"C:\Users\Artur\TCC_UNIV")
DATA_DIR = BASE_DIR / "data"

# 1. Carregar as bases tratadas
df_tse = pd.read_parquet(DATA_DIR / "tse_candidatos_sp_limpo.parquet")
df_ibge = pd.read_parquet(DATA_DIR / "ibge_demografia_sp.parquet")

# 2. Criar a variável Interseccional
df_tse["interseccional"] = df_tse["sexo_std"].str.title() + " - " + df_tse["cor_raca_std"].str.title()
df_ibge["interseccional"] = df_ibge["sexo"].str.title() + " - " + df_ibge["cor_raca"].str.title()

# 3. Contar candidaturas por Ano e Grupo Interseccional
prop_tse = (
    df_tse.groupby(["ANO_ELEICAO", "interseccional"])
    .size()
    .reset_index(name="qtd_candidatos")
)

# Calcular o percentual dentro de cada ano eleitoral usando transform
prop_tse["pct_candidatos"] = (
    prop_tse.groupby("ANO_ELEICAO")["qtd_candidatos"]
    .transform(lambda x: (x / x.sum()) * 100)
)

# 4. Unir com o Benchmark Populacional do IBGE
df_analise = pd.merge(
    prop_tse, 
    df_ibge[["interseccional", "percentual_populacao"]], 
    on="interseccional", 
    how="left"
)

# 5. Calcular a Razão de Representatividade (RR)
df_analise["razao_representatividade"] = (
    df_analise["pct_candidatos"] / df_analise["percentual_populacao"]
).round(2)

# 6. Tabela Pivotada do Índice
tabela_rr = df_analise.pivot(
    index="interseccional", 
    columns="ANO_ELEICAO", 
    values="razao_representatividade"
)

print("\n--- RAZÃO DE REPRESENTATIVIDADE (Candidatos / População IBGE) ---")
print("Valores < 1.0 = Sub-representado | Valores > 1.0 = Sobre-representado")
display(tabela_rr)

# 7. Gráfico de Disparidade Interseccional
plt.figure(figsize=(12, 6))
sns.set_theme(style="whitegrid")

top_grupos = df_ibge.sort_values(by="percentual_populacao", ascending=False)["interseccional"].unique()
df_chart = df_analise[df_analise["interseccional"].isin(top_grupos)]

ax = sns.lineplot(
    data=df_chart,
    x="ANO_ELEICAO",
    y="razao_representatividade",
    hue="interseccional",
    marker="o",
    linewidth=2.5
)

# Linha de paridade ideal (1.0)
plt.axhline(1.0, color="red", linestyle="--", alpha=0.8, label="Paridade Demográfica (1.0)")

plt.title("Evolução da Razão de Representatividade Interseccional em SP (2012–2024)", fontsize=14, pad=15)
plt.xlabel("Ano da Eleição", fontsize=12)
plt.ylabel("Razão de Representatividade (RR)", fontsize=12)
plt.xticks([2012, 2016, 2020, 2024])
plt.legend(title="Grupo Interseccional", bbox_to_anchor=(1.05, 1), loc="upper left")
plt.tight_layout()

plt.show()

# Exportar resultado final
df_analise.to_csv(DATA_DIR / "resultado_representatividade_interseccional.csv", index=False)
print(f"✅ Análise concluída! Arquivo salvo em: {DATA_DIR / 'resultado_representatividade_interseccional.csv'}")

Principais Insights dos Dados¶

Dominância Masculina (Sobre-representação): Os homens negros (Masculino - Preta, com RR atingindo 2,79 em 2024) e homens brancos (Masculino - Branca, com RR em 1,34) mantêm proporções de candidaturas significativamente superiores ao seu peso na população.

Disparidade de Gênero Intra-raça (Sub-representação): A desigualdade fica evidente ao comparar homens e mulheres do mesmo grupo racial. Enquanto a candidatura de homens pardos aproxima-se da paridade (0,98 em 2024), a de mulheres pardas permanece em forte sub-representação (0,50).

Trajetória de Crescimento: O grupo Feminino - Preta apresenta uma curva ascendente constante na Razão de Representatividade (de 1,05 em 2016 para 1,58 em 2024), ultrapassando a marca de paridade nas candidaturas.

# 1. Mapeamento
mapa_genero = {"masculino": "MASCULINO", "feminino": "FEMININO"}
mapa_raca = {
    "branca": "BRANCA",
    "preta": "PRETA",
    "parda": "PARDA",
    "amarela": "AMARELA",
    "indigena": "INDIGENA"
}

df_tse["DS_COR_RACA"] = df_tse["DS_COR_RACA"].astype(str).str.strip().str.lower()

df_tse["sexo_std"] = df_tse["DS_GENERO"].map(mapa_genero)
df_tse["cor_raca_std"] = df_tse["DS_COR_RACA"].map(mapa_raca)

# 2. Desduplicação por Candidato
df_tse_limpo = df_tse.dropna(subset=["sexo_std", "cor_raca_std"]).drop_duplicates(subset=["ANO_ELEICAO", "SEQUENCIAL"]).copy()

status_resultado = df_tse_limpo["DS_SIT_TOT_TURNO"].astype(str).str.lower()
df_eleitos = df_tse_limpo[status_resultado.str.contains("eleito", na=False)].copy()

totais_candidatos = df_tse_limpo.groupby(["ANO_ELEICAO", "interseccional"]).size().reset_index(name="qtd_candidatos")
totais_eleitos = df_eleitos.groupby(["ANO_ELEICAO", "interseccional"]).size().reset_index(name="qtd_eleitos")

tabela_sucesso = df_sucesso.pivot(index="interseccional", columns="ANO_ELEICAO", values="taxa_sucesso_pct").round(2)

1. Hiato Genérico de Gênero (Gender Gap)

  • Vantagem Masculina Constante: Em quase todas as combinações de cor/raça e em todos os anos analisados, os homens apresentam uma taxa de sucesso sistematicamente superior às mulheres.
  • Superação dos 50% em 2024: Em 2024, quatro das cinco categorias masculinas (Branca, Indígena, Parda e Preta) ultrapassaram a barreira dos 50% de taxa de sucesso. Nenhuma categoria feminina atingiu a marca de 50% no mesmo ano (a maior foi Feminino - Preta com 45,57%).

2. Tendência Global de Alta (2016 vs. 2024)

  • Crescimento Generalizado: A taxa de conversão de candidaturas em vitórias subiu para quase todas as interseções no período de 8 anos, sugerindo maior concentração de votos ou diminuição do número total de candidaturas "laranjas"/inviáveis após as mudanças na legislação eleitoral.
  • Avanço das Mulheres Negras:
  • Feminino - Preta subiu de 32,26% (2016) para 45,46% (2024).
  • Feminino - Parda subiu de 29,75% (2016) para 43,14% (2024).

3. Comportamento das Populações Indígenas e Amarelas

  • Alta Volatilidade: Os grupos Indígena e Amarela (tanto masculino quanto feminino) mostram variações mais bruscas entre as eleições (ex: Feminino - Indígena saltou de 40,00% em 2016 para 66,67% em 2020 e recuou para 40,54% em 2024).
  • Causa Amostral: Essa oscilação acentuada é típica de amostras pequenas (baixo número absoluto $N$ de candidatos nessas categorias no estado de SP).

4. O "Teto de Vidro" das Mulheres Brancas

  • Apesar de historicamente possuírem maior volume de recursos e tempo de TV em relação às candidatas não-brancas, as mulheres brancas registraram uma das menores taxas de sucesso em 2016 (28,89%) e fecharam 2024 com 43,56%, ficando abaixo das mulheres pretas (45,46%) e amarelas (45,57%).
